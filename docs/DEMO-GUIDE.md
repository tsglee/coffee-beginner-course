# 佛我咖啡：可操作熟豆展示站

本次是靜態網站展示版，沒有正式登入、多人資料庫、付款、物流或對外寄信。價格、庫存、烘焙耗時、批次、顧客與訂單都是示範設定；產區與產品圖片為示意。市場參考資料與來源在 [價格調查](coffee-price-survey-2026-10-13.md)。

## 啟動與頁面

在此 repo 執行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

- 首頁：http://127.0.0.1:4173/index.html
- 咖啡課程：http://127.0.0.1:4173/courses.html
- 5 款熟豆：http://127.0.0.1:4173/shop.html
- 商品詳情範例：http://127.0.0.1:4173/product.html?id=yirgacheffe
- 購物車／示範結帳：http://127.0.0.1:4173/checkout.html
- 管理後台：http://127.0.0.1:4173/admin-orders.html

同一瀏覽器、同一網站來源的頁面共用展示資料。不同電腦、不同瀏覽器或不同網址來源不會共用。瀏覽器允許 localStorage 且空間足夠時，重新整理會保留編輯。可透過 JSON 匯出／匯入移轉或還原。

## 前台

首頁有三張原創照片，預設每 6 秒淡入淡出切換，提供上一張／下一張、定位點與暫停。尊重系統減少動態設定；切到背景分頁或聚焦輪播控制時停止自動換圖。後台可設定 4–30 秒間隔。

商品列出 5 款烘焙熟豆，可依名稱、國家、風味、烘焙度搜尋／篩選，並以 250g 售價或烘焙日期排序。每款含六張不同的圖片：豆子、產區、豆子細節、包裝、品飲與烘焙情境。商品詳情可切換、放大圖片，並顯示：

- 國家、產區、處理法、已公布品種與參考風味；未公布資料保留「依批次確認」。
- 250g／500g 每包淨重、獨立展示價與獨立可售包數。
- 購買包數 × 每包克數 = 購買總淨重。
- 最新完成批次的烘焙日期、耗時、烘焙批號與烘焙度展示設定。
- 起始沖煮建議、保存方式、風味強度示意，以及官方參考價格的原始包裝規格和來源網址。

風味強度不是實測杯測分數，圖片不是某一真實批次或莊園紀錄。展示價不是供應商報價，也不是將不同品牌的原包裝售價直接換算成 250g 的真實價格。

## 後台工作流程

1. **商品管理**：新增、編輯、上下架、刪除無訂單紀錄的商品。可編輯規格價格、風味與圖片，調整圖片順序、說明，並上傳 JPG／PNG／WebP。上傳圖片會在瀏覽器最佳化為最多 1000px 的 JPEG；沒有伺服器上傳。每款至少五張不同圖片。
2. **庫存管理**：每個重量是一個 SKU，以包為單位異動，另顯示可售總克數。每次異動需要原因並留下紀錄。商品編輯不能直接覆寫庫存。
3. **烘焙批次**：新增排程，輸入日期、烘焙耗時，以及 250g／500g 包裝數量；依序開始烘焙、完成入庫。完成會增加對應包數，更新商品最新批次，且不能重複入庫。未到日期不能完成。
4. **訂單管理**：前台下單會驗證目前可售包數、扣庫存並保存價格快照。可依「新訂單 → 已確認 → 備貨中 → 已出貨 → 已完成」操作；出貨必填物流單號。可標示本機收款記錄，不是真實付款。
5. **取消／退款記錄**：出貨前取消會釋放庫存一次。已標記收款的取消訂單轉為待退款，再由管理員標記示範退款完成。已出貨訂單不能直接取消，真實退貨處理未串接。
6. **報表**：計算有效訂單、示範收款、商品包數、總淨重與各商品金額，排除取消訂單。
7. **設定／備份**：修改商店名稱、客服信箱、展示運費、免運門檻與輪播間隔。CSV／JSON 匯出提供內容預覽、複製與檔案下載；可匯入 JSON 檔案或直接貼上備份。先驗證格式、SKU、金額、圖片與批次關聯再套用。還原前可以先匯出資料。

這些管理頁沒有安全登入閘門；資料屬於各自的本機瀏覽器，不可當成正式營運後台。

## 驗證

```sh
node tests/store.test.cjs
```

資料邏輯驗證包含：5 款與圖片／SKU 檢查、庫存不足拒單、下單扣庫存、取消只釋放一次、出貨流程／物流單號、價格快照、烘焙批次只入庫一次、儲存失敗完整回滾、備份匯入與壞資料拒絕。

瀏覽器實測：三張照片自動／手動輪播與暫停、商品圖切換、500g 規格與重量計算、購物車／示範下單、後台取消釋放庫存、批次完成更新商品、商品 CRUD、圖片上傳、JSON 內容匯出與貼上匯入、CSV 內容與報表。原生檔案下載未取得內建瀏覽器的完成事件，因此下載動作的驗證尚有限制；匯出內容預覽、複製選項與資料匯入可作為替代。

## 實作邊界

`assets/catalog-data.js` 為初始示範資料；`assets/store.js` 管理交易與驗證；`assets/commerce.js` 渲染選購、商品與結帳；`assets/admin.js` 管理後台。庫存依 SKU 彙總，商品顯示最新完成的展示批次，不提供逐包 FIFO 實際追溯。品牌故事／關於我們已整理為中英文共用的響應式版型，詳見 [英文版與手機排版](ENGLISH-RWD.md)。若要投入正式營運，登入、角色權限、伺服器資料庫、訂單一致性、付款與物流應另行接入。交接給其他代理時請先閱讀 [Agent handoff](AGENT-HANDOFF.md)。
