# Google Stitch design → local implementation

The original screen was generated by Google Stitch for this project. See `provenance.json`, `prompt.txt`, `original.html`, `original.png` and `design-system.md`.

The local `/stitch/` page preserves the source design's ivory navigation, cinematic teal hero, brass chapter notation, three-column tuition metadata, framed asymmetric chapter spreads, vertical learning timeline, serif headings and square controls. `assets/stitch.css` implements that art direction without Tailwind CDN or a runtime Stitch dependency.

The generated draft contained speculative brewing temperatures, ratios, strict quality classifications, and additional teaching claims. These were replaced with the confirmed shared course content. Existing real instructor photos replace placeholders. Eleven project images were generated with the built-in GPT image tool, including a dedicated Stitch hero photograph. FAQ, mobile menu, parameter tips and LINE links were completed locally.

The first generation yielded an image screen rather than a complete HTML screen. The second generation in the same project yielded the complete website design recorded in `provenance.json`; no duplicate Stitch project was created.

Credentials are supplied over hidden stdin to the development helper. They are never saved to this repository and are unnecessary for building or browsing the completed site.
